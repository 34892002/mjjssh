# 终端底部命令栏产品设计

## 目标

为每个 SSH 和本地终端页签提供一个位于终端下方的命令输入栏。输入栏与 xterm 处于同一会话视图但不覆盖终端输出；用户可使用单行输入直接执行命令、回填终端选区、查看项目级命令历史、重新连接 SSH 会话，以及关闭或重新打开命令栏。

## 布局与动画

- 命令栏位于 `Terminal.vue` 内，与 xterm 容器为纵向同级布局。
- 命令栏显示时占用固定的底部高度；关闭时整个命令栏容器从文档流移除，终端容器填满释放出的区域。
- 命令栏关闭后，在终端右下角显示半透明的恢复按钮。该按钮使用绝对定位，不参与文档流，也不占用终端布局空间。
- 点击恢复按钮后显示命令栏并自动聚焦输入框。
- 终端容器尺寸发生实际变化时，由既有 `ResizeObserver` 重新 fit，并向 SSH/local PTY 同步尺寸。

## 会话状态

下列状态按 `sessionId` 隔离，切换页签后保持：

- 当前命令草稿。
- 命令栏显示/关闭状态。
- 历史面板打开状态和当前历史选择位置。

## 输入与执行

- 输入框只支持单行文本；`Enter` 将非空文本附加 `\r` 后发送到当前终端执行。
- 命令发送成功后清空输入框；失败时保留草稿，终端既有的不可用状态提示仍作为传输失败反馈。
- AI 识别按钮仅保留界面位置，本期不接入 AI 调用。
- 重新连接按钮只对 SSH 会话显示，由父组件发起既有重连流程。

## 快捷键

### 左 Ctrl

当 xterm 有选区时，独立按下并释放左 Ctrl 会把选区文本写入当前会话的命令输入框。

- 必须是左 Ctrl，且按下到释放期间没有其他按键参与。
- 存在 Ctrl 组合键时不触发回填。
- 回填不向远端发送数据。
- 命令栏关闭时，此快捷键不生效，不会重新打开命令栏。

### Alt

独立按下并释放 Alt 切换历史面板。

- 再次独立按下并释放 Alt 关闭面板。
- 命令栏关闭时，此快捷键不生效，不会重新打开命令栏。
- `Alt + 字符` 继续遵守终端设置并向远端发送，不受该功能影响。
- 历史面板打开时，上/下方向键切换候选项，`Enter` 回填输入框，`Escape` 关闭面板。

## 项目级命令历史

- 历史记录所有 SSH 和本地终端的已提交行：用户从 xterm 或底部命令栏输入并发送 `Enter` 后记录。
- 历史不按会话区分；所有页签共享同一列表。
- 历史持久化在加密 Vault 中，最多保留最近 500 条；重复命令移动到列表首位。
- 用户在 xterm 中按 `Ctrl+C` 取消的未提交文本不记录。
- 全屏或交互式终端程序中的 Enter 无法从客户端可靠识别为 Shell 命令，仍按已提交终端行记录，这是客户端可实现的统一边界。
- 历史面板提供“清空列表”按钮，一次清除全部项目级历史。

## 操作区

从左至右：

1. `AI 识别` 占位按钮。
2. 历史图标，切换历史面板。
3. 重新连接图标（闪电），仅 SSH 会话可用。
4. 关闭图标，关闭整个命令栏容器。

命令栏关闭后，终端右下角显示 `PanelBottomOpen` 悬浮图标，用于重新打开命令栏。

所有图标按钮必须使用 Lucide 图标，并提供 `title` 与 `aria-label`。

## 实现边界

- 命令栏由 `Terminal.vue` 承载，终端输入和命令栏发送统一进入会话写入链路。
- 后端在 Vault 中提供读取、记录、清空命令历史的 Tauri 命令；前端不得使用浏览器本地存储保存历史。
- 不修改 SSH 协议、远端 Shell 配置或服务器环境。
- 命令栏关闭后，仅保留终端原有输入和已提交命令历史采集；命令栏的左 Ctrl、Alt 和历史快捷键均不响应，必须点击右下角恢复按钮重新打开。
- 终端保持 `v-show` 存活，所有 DOM 监听器在组件卸载时释放。

## 验收标准

1. 关闭命令栏后，终端填满释放出的高度；恢复命令栏后，终端输出不被覆盖且 xterm 尺寸同步正常。
2. 输入框按 Enter 可在当前 SSH/local 终端执行单行命令。
3. SSH 窗口选区后独立单击左 Ctrl，可回填输入框；Ctrl 组合键不触发。
4. 单击 Alt 可开关历史；Alt+字符仍可输入远端终端。
5. 所有终端已提交命令均出现在跨会话共享的历史中，重启应用后仍存在。
6. 历史上/下选择、Enter 回填、Escape 关闭和清空列表均可用。
7. SSH 会话可通过闪电按钮重新连接；AI 识别按钮仅占位。
8. 命令栏关闭时，左 Ctrl 选区回填和 Alt 历史快捷键不响应；右下角半透明恢复按钮不参与终端文档流，点击后恢复命令栏并聚焦输入框。
